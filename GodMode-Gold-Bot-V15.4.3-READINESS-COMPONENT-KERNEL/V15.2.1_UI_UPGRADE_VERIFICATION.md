# V15.2.1 Early Impulse Settings UI

1. The Settings page exposes every production Early Impulse Predictor key used by the backend.
2. Controls preserve the existing card, field, typography, spacing, colour and responsive conventions.
3. Predictor controls load from verified backend settings and save through the revision-protected settings endpoint.
4. Live diagnostics poll the real `/api/fast-sniper/status` endpoint and display WATCH, PROBE or CONFIRMED state, probability, side, velocity, acceleration, persistence, compression release, spread quality, candle score, sweep risk and displacement.
5. Diagnostics fail safely when MT5 or the backend is unavailable and never invent live values.
6. The existing risk, news, spread, broker-admission, stop-loss and validation gates remain authoritative.
7. Desktop, tablet and mobile layouts remain usable without horizontal overflow.
8. Backend, frontend runtime, release manifest and Tick Guard share the exact V15.2.1 build identity.
9. Python compilation, backend regression tests, JavaScript syntax checks and archive integrity checks pass before release.
