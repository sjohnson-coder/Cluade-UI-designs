# GodMode Gold Bot V15.0.2 — Live Operations Hardened

## Purpose
This release corrects the V15.0.1 operational identity, launcher, frontend deployment and test-isolation defects while retaining the audited V14 interface and V15 shadow-intelligence safeguards.

## Operational corrections
- Exact V15.0.2 build identity across backend, frontend source, deployed HTML, Tick Guard and launchers.
- One-click launcher now waits for the actual V15.0.2 backend and uses a V15.0.2 cache key.
- Visible launcher branding and diagnostics no longer reference V14.1.23 or V15.0.0.
- Release verification now checks launcher identity and deployed HTML metadata.
- Settings persistence tests use temporary files and no longer modify packaged production settings.
- V15 production panel uses one canonical deployed implementation; duplicate React-source mounting was removed.
- Original V14 CSS and principal compiled page bundles remain unchanged.

## Safety boundary
V15 intelligence remains shadow-governed. It cannot independently bypass MT5 connection, Tick Guard, certification, exposure, daily-risk, stop-loss or kill-switch controls.

## Deployment
Extract into a new folder, compile and attach the supplied Tick Guard in the active broker terminal, then run START_GODMODE.bat. Validate on demo before live use.
