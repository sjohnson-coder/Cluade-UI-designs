# V15.4.2 Execution Authority Kernel

## Purpose

Separate backend application health from broker execution authority so validation, certification, market-hours, Tick Guard, reconciliation, or strategy-loop blockers cannot falsely display the entire bot as degraded while still preventing unsafe orders.

## Definition of Done

| Phase | Acceptance criteria | Result |
|---|---|---|
| Application health | `appReady` reflects control-plane availability and persistence, not trading policy | Done |
| Execution authority | One `executionAuthority` object exposes every critical order gate | Done |
| Fail-closed orders | `tradingReady` remains false whenever any execution gate fails | Done |
| UI state | Red global banner is reserved for transport, stale critical data, build mismatch, or genuine app failure | Done |
| Recovery | Successful readiness polling clears prior temporary UI safety states | Done |
| Advisory failures | Optional API and UI-render failures cannot change the global execution safety state | Done |
| Operator feedback | Amber banner shows exact execution-authority blockers without declaring the backend offline | Done |
| Build identity | Backend, frontend, launcher, settings, manifest, and Tick Guard identify V15.4.2 | Done |
| Regression | Full packaged backend suite passes | Done |
| Package integrity | Python, JavaScript, manifest, SHA-256, release verifier, and ZIP CRC pass | Done |

## Key corrections

- Added `appReady`, `tradingReady`, and `executionAuthority` as separate response fields.
- Moved MT5, live switch, dry-run, market, kill switch, reconciliation, validation, certification, Tick Guard, trading-loop, and Priority Intent checks into explicit execution gates.
- Preserved fail-closed order admission through `tradingReady` and the existing pre-live supervisor.
- Prevented non-critical page failures from setting the whole UI to OFFLINE.
- Converted uncaught UI errors into advisory `godmode:ui-error` events rather than global DEGRADED events.
- Changed the operator banner from a false backend-degraded warning to an execution-authority warning with the exact blockers.
